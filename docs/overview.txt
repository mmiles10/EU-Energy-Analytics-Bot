ENERGY TRADING SYSTEM - COMPLETE ARCHITECTURE GUIDE
====================================================

SYSTEM OVERVIEW
---------------
This is a comprehensive energy trading data pipeline that fetches European energy market data, performs analytics, generates visualizations, and sends reports via Telegram.

SYSTEM ARCHITECTURE
------------------

1. CORE DATA PIPELINE (main.py)
Purpose: Main orchestrator that fetches data from ENTSOE API
Key Components:
- ENTSOE API integration using EntsoePandasClient
- Data fetching for 4 data types:
  - Day-ahead prices (pandas Series)
  - Generation data (pandas DataFrame) 
  - Load data (pandas DataFrame)
  - Cross-border flows (pandas Series)
- CSV file generation
- Chart generation
- Analytics integration

Data Flow:
ENTSOE API → Raw Data → CSV Files → Charts → Analytics → Telegram

2. CONFIGURATION (config.py + .env)
Purpose: Non-secret defaults and env-based API access
Contains:
- ENTSOE_API_KEY: Read from environment / .env (never hardcode in this file)
- ENTSOE_BASE_URL: API endpoint URL (non-secret)
- Security: Real credentials only in .env (gitignored); see .env.example

3. DATA ANALYTICS (EnergyAnalysis.py)
Purpose: Comprehensive data analysis and insights
Key Functions:
- load_energy_data(): Loads CSV files into pandas DataFrames
- analyze_prices(): Price statistics, volatility, peak/off-peak analysis
- analyze_load(): Load patterns, peak times, load factor
- analyze_flows(): Cross-border trading flows analysis
- analyze_generation(): Generation mix by fuel type
- correlation_analysis(): Price vs load correlation
- trading_insights(): Risk assessment and arbitrage opportunities
- generate_summary_report(): Comprehensive market overview

4. TELEGRAM INTEGRATION
Multiple Files for Different Purposes:

telegram_bot.py
- Full-featured Telegram bot class
- Message sending capabilities
- Energy report formatting
- Trading alerts system

send_telegram.py
- Simple chat ID discovery
- Basic message sending
- User-friendly interface

test_telegram.py
- Connection testing
- Chat ID: 8466265605
- Bot token integration

send_energy_report.py
- Sends formatted energy reports to phone
- Real-time data integration
- Trading alerts

COMPONENT BREAKDOWN
------------------

A. DATA SOURCES
- ENTSOE Transparency Platform: European energy market data
- API Endpoint: https://web-api.tp.entsoe.eu/api
- Authentication: API key-based
- Data Types: Prices, generation, load, flows

B. DATA PROCESSING
- Library: pandas for data manipulation
- Client: EntsoePandasClient for API interaction
- Output: CSV files with structured data
- Time Series: Timestamp-indexed data

C. VISUALIZATION
- Library: matplotlib
- Chart Types:
  - Line charts (prices, load, flows)
  - Stacked area charts (generation mix)
- Output: PNG files with high DPI

D. ANALYTICS ENGINE
- Statistical Analysis: Mean, min, max, volatility
- Correlation Analysis: Price vs load relationships
- Trading Insights: Risk assessment, arbitrage opportunities
- Market Status: Volatility classification

E. NOTIFICATION SYSTEM
- Platform: Telegram Bot API
- Message Types: Reports, alerts, insights
- Formatting: HTML formatting for rich messages
- Real-time: Instant delivery to mobile device

HOW TO USE THE SYSTEM
---------------------

1. INITIAL SETUP
# Install dependencies
pip install entsoe-py pandas matplotlib requests python-dotenv

# Configure secrets in .env (copy from .env.example)
# ENTSOE_API_KEY=...
# TELEGRAM_TOKEN=...
# TELEGRAM_CHAT_ID=...

2. RUN COMPLETE PIPELINE
python3 main.py
This will:
- Fetch data from ENTSOE
- Generate CSV files
- Create charts
- Run analytics
- Display comprehensive report

3. RUN ANALYTICS ONLY
python3 EnergyAnalysis.py
This will:
- Load existing CSV files
- Perform comprehensive analysis
- Display trading insights

4. SEND TO PHONE
python3 send_energy_report.py
This will:
- Load energy data
- Format report
- Send to Telegram
- Deliver to your phone

TROUBLESHOOTING
---------------

Common Issues:
1. Import Errors: Install missing packages
2. API Errors: Check ENTSOE_API_KEY is set in .env or the environment (never commit real keys)
3. Telegram Issues: Verify TELEGRAM_TOKEN and TELEGRAM_CHAT_ID in .env
4. Data Issues: Ensure CSV files exist before analytics

Debug Commands:
# Test imports
python3 -c "import entsoe, pandas, matplotlib, requests"

# Test API key is present (does not print the secret)
python3 -c "import os; from dotenv import load_dotenv; load_dotenv(); print('ENTSOE_API_KEY set:', bool(os.getenv('ENTSOE_API_KEY')))"

# Test Telegram
python3 test_telegram.py
